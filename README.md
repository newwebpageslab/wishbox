# 위시함 (Wishbox)

갖고 싶은 물건을 모아두고 **네이버 최저가를 바로 찾아볼 수 있는** 개인용 위시리스트 웹앱(PWA)입니다.
안드로이드 크롬에서 "홈 화면에 추가"를 하면 일반 앱처럼 쓸 수 있습니다.

## 주요 기능
- **브랜드명 · 상품명 · 사이트** 직접 입력, 사진 추가 (최대 6장, 기기 안에서 자동 압축)
- 가격·카테고리·메모, "꼭 사고 싶음" 하트, 상품 링크(선택)
- **네이버 최저가 찾기**: 버튼을 누르면 브랜드명+상품명으로 네이버 통합검색 결과가 열림 (가격비교 정보 포함, 로그인 불필요)
  (상세 화면, '최저가 검색' 탭)
- 검색(브랜드·상품명·메모·사이트), 카테고리 필터, 정렬 5종
- 위시 / 구매함 / 포기함 상태 관리 (실행 취소 지원)
- 중복 링크 감지, 가격 기록, 통계(포기로 아낀 돈)
- JSON 백업 내보내기/가져오기, 오프라인 실행

## 데이터와 보안
- 모든 위시는 **휴대폰 브라우저(IndexedDB) 안에만** 저장됩니다. 서버나 API를 쓰지 않습니다.
- "최저가 찾기"는 네이버 검색 페이지를 여는 링크일 뿐이며, 앱이 데이터를 보내지 않습니다.
- 브라우저 데이터를 지우면 위시도 사라지므로, 설정 > 백업 파일 내보내기를 가끔 해두세요.

> 참고: 네이버 쇼핑 검색 API가 2026년 7월 31일 종료되어, 앱 안에서 최저가를 자동으로 가져오는 기능은 넣지 않았습니다.

## PC에서 실행해 보기
```powershell
powershell -ExecutionPolicy Bypass -File tools/serve.ps1
```
브라우저에서 http://localhost:8080 접속.

## 휴대폰에 설치하려면
PWA 설치에는 **HTTPS 주소**가 필요합니다. 현재 GitHub Pages(https://newwebpageslab.github.io/wishbox/)로 배포합니다.
휴대폰 크롬에서 접속 → 메뉴 → "홈 화면에 추가"(또는 "앱 설치")를 누르세요.
올라가는 것은 앱 코드뿐이고, 위시 데이터는 올라가지 않습니다.

## 코드를 수정한 뒤
`sw.js`의 `VERSION` 값을 올려야 휴대폰에 새 버전이 반영됩니다 (앱을 두 번 열면 적용).

## 구조
| 파일 | 역할 |
|---|---|
| `index.html` | 화면 뼈대, 아이콘 |
| `css/app.css` | Apple 스타일 디자인 (라이트/다크, 접근성 설정 대응) |
| `js/app.js` | 목록·추가/편집·상세·최저가 찾기 탭·설정·백업 |
| `js/sheet.js` | 바텀 시트 (드래그·플릭으로 닫기, 뒤로가기 연동) |
| `js/spring.js` | 스프링 애니메이션, 속도 추적, 모멘텀 투영 |
| `js/meta.js` | 링크 정리, 사이트 이름 추측, 네이버 검색 링크 만들기 (네트워크 사용 없음) |
| `js/images.js` | 사진 압축·썸네일 |
| `js/db.js` | IndexedDB 저장소 |
| `sw.js`, `manifest.webmanifest` | 오프라인·설치·공유 받기 |
| `tools/` | 로컬 서버, 아이콘 생성 스크립트 |
