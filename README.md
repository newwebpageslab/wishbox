# 위시함 (Wishbox)

갖고 싶은 물건을 **상품 링크**나 **캡처 사진**으로 모아두는 개인용 위시리스트 웹앱(PWA)입니다.
안드로이드 크롬에서 "홈 화면에 추가"를 하면 일반 앱처럼 쓸 수 있습니다.

## 주요 기능
- 링크 붙여넣기 / 캡처·사진 추가 (최대 6장, 기기 안에서 자동 압축)
- 상품명·가격·목표가·카테고리·우선순위·메모("왜 갖고 싶은지")
- 검색(상품명·메모·쇼핑몰), 카테고리 필터, 정렬 6종
- 위시 / 구매함 / 포기함 상태 관리 (실행 취소 지원)
- **목표가 도달 알림**: 가격을 수정하거나 자동 확인했을 때 목표가 이하이면 알림
- 중복 링크 감지, 가격 기록, 통계(포기로 아낀 돈)
- JSON 백업 내보내기/가져오기, 오프라인 실행
- 다른 앱의 "공유하기"로 링크 받기 (설치 후)

## 데이터와 보안
- 모든 데이터는 **휴대폰 브라우저(IndexedDB) 안에만** 저장됩니다. 서버가 없습니다.
- 선택 기능인 "링크 정보 자동 채우기"를 켜면, 쇼핑몰 페이지를 읽기 위해 **상품 링크 주소만** 외부 프록시(기본값 `api.allorigins.win`)를 거칩니다. 기본값은 꺼져 있습니다.
- 브라우저 데이터를 지우면 위시도 사라지므로, 설정 > 백업 파일 내보내기를 가끔 해두세요.

## PC에서 실행해 보기
```powershell
powershell -ExecutionPolicy Bypass -File tools/serve.ps1
```
브라우저에서 http://localhost:8080 접속.

## 휴대폰에 설치하려면
PWA 설치에는 **HTTPS 주소**가 필요합니다. 정적 호스팅(GitHub Pages, Netlify, Cloudflare Pages 등)에 이 폴더를 올린 뒤
휴대폰 크롬에서 접속 → 메뉴 → "홈 화면에 추가"(또는 "앱 설치")를 누르세요.
올라가는 것은 앱 코드뿐이고, 위시 데이터는 올라가지 않습니다.

## 코드를 수정한 뒤
`sw.js`의 `VERSION` 값을 올려야 휴대폰에 새 버전이 반영됩니다 (앱을 두 번 열면 적용).

## 구조
| 파일 | 역할 |
|---|---|
| `index.html` | 화면 뼈대, 아이콘 |
| `css/app.css` | Apple 스타일 디자인 (라이트/다크, 접근성 설정 대응) |
| `js/app.js` | 목록·추가/편집·상세·설정·알림·백업 |
| `js/sheet.js` | 바텀 시트 (드래그·플릭으로 닫기, 뒤로가기 연동) |
| `js/spring.js` | 스프링 애니메이션, 속도 추적, 모멘텀 투영 |
| `js/meta.js` | 링크 정리, 쇼핑몰 이름, 상품 정보 파싱 |
| `js/images.js` | 사진 압축·썸네일 |
| `js/db.js` | IndexedDB 저장소 |
| `sw.js`, `manifest.webmanifest` | 오프라인·설치·공유 받기 |
| `tools/` | 로컬 서버, 아이콘 생성 스크립트 |
