# 위시함 클라우드 저장 설정 (Supabase)

휴대폰 데이터가 지워져도 위시가 남도록, 위시와 사진을 Supabase(무료 클라우드 DB)에도 저장합니다.
처음 한 번만 설정하면 되고 15분 정도 걸립니다.

> 키나 비밀번호는 채팅에 붙여넣지 말고, 각 화면에 직접 입력하세요.

---

## 1단계. 프로젝트 만들기
1. https://supabase.com 에 가입하고 로그인합니다. GitHub 계정으로도 가입할 수 있습니다.
2. **New project**를 누릅니다.
   - Name: `wishbox`
   - Database Password: 안전한 비밀번호를 정하고 따로 보관하세요. 앱에서는 쓰지 않습니다.
   - Region: **Northeast Asia (Seoul)**
3. **Create new project**를 누르고 1~2분 기다립니다.

## 2단계. 테이블과 사진 저장소 만들기
1. 왼쪽 메뉴에서 **SQL Editor**를 엽니다.
2. 이 저장소의 [`supabase/setup.sql`](setup.sql) 내용을 전부 복사해 붙여넣고 **Run**을 누릅니다.
3. "Success"가 나오면 끝입니다.
   - 만들어지는 것: `wishes` 테이블, 비공개 사진 저장소 `wish-images`
   - 함께 걸리는 잠금(RLS): **로그인한 본인만 자기 데이터를 읽고 쓸 수 있습니다.**

## 3단계. 내 로그인 계정 만들기
1. 왼쪽 메뉴에서 **Authentication → Users → Add user → Create new user**를 누릅니다.
2. 앱에서 쓸 이메일과 비밀번호를 입력하고, **Auto Confirm User**를 체크한 뒤 만듭니다.
3. (권장) **Authentication → Sign In / Providers**에서 **Allow new users to sign up**을 끕니다.
   앱 코드가 공개돼 있어서, 이걸 끄면 다른 사람이 세영님 프로젝트에 계정을 만들 수 없습니다.

## 4단계. 앱 연결 정보 확인하기
1. **Project Settings → Data API**(또는 프로젝트 홈의 **Connect**)에서 **Project URL**을 복사합니다.
   예: `https://abcdefgh.supabase.co`
2. **Project Settings → API Keys**에서 **Publishable key**(`sb_publishable_…`)를 복사합니다.
   - 이 키는 앱에 넣어도 되는 공개용 키입니다. 데이터는 2단계의 잠금으로 보호됩니다.
   - **Secret key(`sb_secret_…`)는 절대 앱에 넣지 마세요.**

## 5단계. 휴대폰 앱에서 로그인
1. 위시함 → **설정(⚙) → 클라우드 저장 (Supabase)**로 들어갑니다.
2. 프로젝트 URL, Publishable key, 3단계의 이메일과 비밀번호를 입력합니다.
3. **로그인하고 동기화 시작**을 누릅니다.
4. "클라우드에 연결했어요 · N개 올림"이 뜨면 휴대폰에 있던 위시가 모두 클라우드에 올라간 것입니다.

이후에는 위시를 저장·수정·삭제할 때마다 자동으로 클라우드에 반영됩니다.

---

## 알아두면 좋은 점
- **복구**: 휴대폰 데이터가 지워지거나 폰을 바꿔도 5단계처럼 다시 로그인하면 위시와 사진이 돌아옵니다.
- **오프라인**: 인터넷이 없을 때도 앱은 그대로 쓸 수 있고, 연결되면 자동으로 맞춰집니다.
- **동시 수정**: 같은 위시를 두 기기에서 고치면 더 나중에 고친 쪽이 남습니다.
- **일시정지**: 무료 프로젝트는 7일 동안 사용이 없으면 일시정지될 수 있습니다.
  이때 설정 아이콘에 빨간 점이 뜹니다. Supabase 대시보드에서 프로젝트를 다시 켜면 데이터는 그대로입니다.
- **무료 한도**: DB 500MB, 사진 1GB입니다. 사진은 앱에서 압축해서 올리기 때문에 위시 수천 개까지 여유 있습니다.
- **저장되는 것**: 위시 정보(브랜드명, 상품명, 사이트, 가격, 링크, 카테고리, 메모, 하트, 상태)와 사진입니다.
  비밀번호는 휴대폰에 저장하지 않고, 로그인 후 받은 토큰만 저장합니다.

## 문제가 생기면
| 표시 | 해결 |
|---|---|
| 이메일 또는 비밀번호가 맞지 않아요 | 3단계에서 만든 계정 정보 확인, Auto Confirm 체크 여부 확인 |
| Supabase에 연결할 수 없어요 | 프로젝트 URL 오타 확인, 프로젝트가 일시정지됐는지 대시보드 확인 |
| Supabase 오류 (401) | Publishable key를 다시 복사해 입력 |
| Supabase 오류 (404 / relation does not exist) | 2단계 SQL을 실행했는지 확인 |
| Supabase 오류 (403) | 2단계 SQL을 다시 실행 (잠금 설정 누락) |
